A single 125-character roast from a smart fridge that refuses to open after midnight: its sensor log catches the owner at 02:14 spending eight minutes sweet-talking a locked door, then drinking soy sauce straight from the packet — and the fridge keeps the receipt. The punch lands on the human ("I have photos."), never on the fridge itself.

## Run it

```sh
node main.ts
```
